# 🌲 Módulo Personal para Vaesen RPG

Este repositorio contiene un módulo personalizado para el juego de rol de mesa **Vaesen: Ritos Nórdicos y Mitos Antiguos**, diseñado específicamente para ser utilizado en **mis campañas privadas y partidas personales**.

---

## 📋 Descripción

El objetivo de este módulo es centralizar compendios, automatizaciones, ajustes visuales, reglas caseras (*house rules*) y recursos específicos adaptados al estilo y desarrollo de nuestras partidas.

> ⚠️ **Nota:** Este proyecto es de uso personal y recreativo. No está pensado como un módulo público ni de distribución general.

---

## 🛠️ Contenido e Inclusiones

- **Misterios y Aventuras:** Compendios de escenas, notas y diarios para el Director de Juego.
- **Vaesen y PNJs:** Fichas preparadas, criaturas y personajes no jugadores específicos de la campaña.
- **Recursos Visuales y Macros:** Tableros, artefactos, macros de ayuda y utilidades de automatización.
- **Ajustes de Reglas:** Reglas caseras e integraciones adaptadas a mesa.

---

## ⚙️ Instalación (Uso Personal)

1. Descarga o clona este repositorio en la carpeta correspondiente de módulos de tu entorno de juego (ej. Foundry VTT).
2. Activa el módulo desde los ajustes de la partida.
3. ¡Listo para jugar!
